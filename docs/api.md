# Спецификация REST API

В данном разделе описаны основные маршруты API информационной системы «Автосалон», используемые клиентским SPA-интерфейсом для динамического взаимодействия с сервером.

## 1. Получение каталога автомобилей
*   **Метод и адрес:** `GET /api/cars/`
*   **Назначение:** Загрузка списка доступных автомобилей. Поддерживает динамическую фильтрацию через query-параметры (поиск, марка, сортировка).
*   **Аутентификация:** Не требуется (AllowAny).
*   **Тело запроса:** Пустое.
*   **Успешный ответ (HTTP 200):**
    ```json
    [
      {
        "id": 1,
        "brand": {"id": 1, "name": "Audi"},
        "model_name": "A3",
        "year": 2023,
        "price": "2800000.00",
        "image_url": "https://hips.hearstapps.com/hmg-prod/images/new-audi-a3-sedan-101-1595373883.jpg?crop=0.738xw:0.623xh;0.0440xw,0.0954xh&resize=2048:*",
        "is_available": true
      }
    ]
    ```
*   **Ошибки:** Системные ошибки сервера (HTTP 500).

## 2. Создание заявки на покупку
*   **Метод и адрес:** `POST /api/orders/`
*   **Назначение:** Оформление новой клиентской заявки на выбранный автомобиль.
*   **Аутентификация:** Не требуется (AllowAny), требуется CSRF-токен.
*   **Тело запроса (JSON):**
    ```json
    {
      "car": 1,
      "client_name": "Alex",
      "client_phone": "+7 (999) 123-45-67"
    }
    ```
*   **Успешный ответ (HTTP 201 Created):** Возвращает JSON созданного объекта заявки со статусом `new`.
*   **Ошибки:** 
    *   `HTTP 400 Bad Request` — ошибка валидации (не заполнены обязательные поля).

## 3. Изменение статуса заявки (Бизнес-транзакция)
*   **Метод и адрес:** `PATCH /api/orders/{id}/`
*   **Назначение:** Изменение статуса заявки менеджером (перевод в работу, отмена, завершение). Запускает транзакцию с записью в аудит (`OrderEvent`) и изменением складского статуса авто (`is_available`).
*   **Аутентификация:** Требуется сессия сотрудника (`IsAdminUser`) и CSRF-токен.
*   **Тело запроса (JSON):**
    ```json
    {
      "status": "process"
    }
    ```
*   **Успешный ответ (HTTP 200 OK):** Возвращает JSON обновленной заявки.
*   **Ошибки:** 
    *   `HTTP 400 Bad Request` — недопустимый переход статуса (например, отмена закрытой сделки) или автомобиль уже продан.
    *   `HTTP 403 Forbidden` — попытка доступа без прав менеджера.
    *   `HTTP 404 Not Found` — заявка с указанным ID не существует.

## 4. Удаление заявки
*   **Метод и адрес:** `DELETE /api/orders/{id}/`
*   **Назначение:** Удаление заявки менеджером. Освобождает связанный автомобиль для продажи.
*   **Аутентификация:** Требуется сессия сотрудника (`IsAdminUser`) и CSRF-токен.
*   **Тело запроса:** Пустое.
*   **Успешный ответ:** `HTTP 204 No Content` (без тела ответа).
*   **Ошибки:** 
    *   `HTTP 400 Bad Request` — удаление заблокировано (заявка находится на этапе «В обработке»).
    *   `HTTP 403 Forbidden` — нет прав доступа.
