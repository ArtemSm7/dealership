# Типичные ошибки и диагностика

В данном разделе описаны 5 типичных проблем, которые могут возникнуть при развёртывании проекта, и способы их устранения.

## 1. Ошибка: DisallowedHost (HTTP 400 Bad Request)
* **Симптом:** При открытии сайта отображается статус 400 Bad Request, а в логах сервера (Render) зафиксировано исключение `DisallowedHost`.
* **Причина:** Значение переменной `DJANGO_ALLOWED_HOSTS` не совпадает с фактическим адресом, по которому происходит обращение.
* **Исправление:** Проверить публичный URL платформы и вписать его точное значение (без протокола `https://` и слешей) в панель Environment Variables. Перезапустить сервис.

## 2. Ошибка: ProgrammingError: relation does not exist (HTTP 500)
* **Симптом:** Сайт открывается, но при попытке получить данные (например, каталог авто) возникает ошибка 500.
* **Причина:** Подключение к PostgreSQL работает, но в базе нет необходимых таблиц. Команда миграций не была выполнена после создания пустой БД.
* **Исправление:** Открыть консоль сервиса (Shell) и вручную выполнить команду `python manage.py migrate`, либо совершить миграции через `build.sh`.

## 3. Проблема: Данные исчезают после перезапуска сервера
* **Симптом:** Заявки сохраняются, но при следующем деплое или перезапуске вся база данных обнуляется.
* **Причина:** Отсутствует или неверно указана переменная `DATABASE_URL`. Django переключился на резервную локальную базу `db.sqlite3`, которая хранится на временном диске облака и стирается при каждом запуске.
* **Исправление:** Подключить постоянную БД PostgreSQL, скопировать её `Internal Database URL` и вставить в переменную `DATABASE_URL` веб-сервиса[cite: 2].

## 4. Ошибка: CSRF Failed (HTTP 403 Forbidden)
* **Симптом:** При попытке изменить статус заявки или добавить машину API отклоняет POST/PATCH запрос со статусом 403.
* **Причина:** Запрос отправлен с доверенного HTTPS-домена, но сам домен не внесен в белый список доверенных источников для проверки токенов.
* **Исправление:** В панель переменных окружения добавить переменную `DJANGO_CSRF_TRUSTED_ORIGINS` с полным HTTPS-адресом сайта (обязательно с `https://`).

## 5. Проблема: Сайт открывается "сломанным" (без стилей)
* **Симптом:** Страница загружается, но верстка полностью отсутствует, в консоли браузера (F12) ошибки 404 Not Found на CSS/JS файлах.
* **Причина:** Процесс сборки статики завершился с ошибкой или не был запущен. 
* **Исправление:** Убедиться, что в настройках Build Command указано исполнение `bash build.sh`, внутри которого прописана команда `python manage.py collectstatic --noinput`. Проверить логи сборки.
