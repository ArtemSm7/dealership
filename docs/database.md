# Схема базы данных

База данных автосалона спроектирована с использованием реляционных связей Django ORM. Она состоит из следующих основных сущностей:

## 1. Brand (Марка автомобиля)
Справочник производителей.
*   `id` (Primary Key) — уникальный идентификатор.
*   `name` (String) — название марки.

## 2. Car (Автомобиль)
Складской ресурс автосалона.
*   `id` (Primary Key) — уникальный идентификатор.
*   `brand` (ForeignKey) — связь с таблицей `Brand`.
*   `model_name` (String) — название модели.
*   `year` (Integer) — год выпуска.
*   `price` (Decimal) — стоимость автомобиля.
*   `is_available` (Boolean) — статус доступности (свободен / забронирован).

## 3. Order (Заявка на покупку)
Основная бизнес-сущность.
*   `id` (Primary Key) — уникальный идентификатор.
*   `car` (ForeignKey) — связь с таблицей `Car`.
*   `client_name` (String) — имя клиента.
*   `client_phone` (String) — контактный телефон.
*   `status` (String) — текущее состояние заявки (`new`, `process`, `done`, `canceled`).
*   `created_at` (DateTime) — дата и время поступления заявки.

## 4. OrderEvent (История событий / Аудит)
Журнал автоматической фиксации переходов состояний.
*   `id` (Primary Key) — уникальный идентификатор.
*   `order` (ForeignKey) — связь с заявкой (`Order`), каскадное удаление.
*   `initiator` (ForeignKey) — менеджер (пользователь системы), выполнивший действие.
*   `old_status` (String) — статус до изменения.
*   `new_status` (String) — статус после изменения.
*   `created_at` (DateTime) — точное время фиксации транзакции.
