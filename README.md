# Информационная система «Автосалон»

## Назначение
Программное решение предназначено для автоматизации бизнес-процессов автосалона. Система позволяет клиентам просматривать каталог доступных автомобилей и оставлять заявки на покупку, а менеджерам — управлять складом и отслеживать статусы клиентских обращений.

## Функциональность
*   **Клиентская часть:** Просмотр каталога автомобилей, добавление машин в избранное, оформление заявки на покупку.
*   **Панель менеджера:** Просмотр списка заявок, изменение статуса заявок (в обработке, продано, отменено).
*   **Архитектура SPA:** Основные взаимодействия с сервером (фильтрация, добавление в избранное, смена статусов) происходят асинхронно без перезагрузки страниц.
*   **Ограничения:** Для доступа к изменению статусов заявок требуется авторизация (сессионная аутентификация менеджера).

## Технологии
*   **Backend:** Python 3, Django, Django REST Framework (DRF).
*   **Frontend:** HTML5, Vanilla JS (Fetch API), UI-фреймворк Tabler.
*   **СУБД:** SQLite (локальная разработка) / PostgreSQL (промышленная эксплуатация).
*   **Production-окружение:** Gunicorn (WSGI-сервер), WhiteNoise (раздача статики), dj-database-url.

## Подготовка к локальному запуску
1. Убедитесь, что установлен Python 3.10 или выше.
2. Клонируйте репозиторий и перейдите в папку проекта.
3. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Для Windows
   # source venv/bin/activate  # Для Linux/macOS
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
## Настройка конфигурации
1. Создайте в корне проекта файл .env на основе предоставленного шаблона .env.example.
2. Для локального запуска достаточно минимальных безопасных значений (подробное описание переменных см. в .env.example).

## Запкск
1. Примените миграции для создания локальной базы данных SQLite:
   ```bash
   python manage.py migrate
   ```
2. Создайте суперпользователя для доступа к админ-панели (опционально):
   ```bash
   python manage.py createsuperuser
   ```
3. Запустите локальный сервер разработки:
   ```bash
   python manage.py runserver
   ```
4. Интерфейс приложения будет доступен по адресу: http://127.0.0.1:8000/

## Проверка работоспособности
1. UI и БД: Откройте главную страницу http://127.0.0.1:8000/. При наличии машин в базе должен отобразиться каталог (дизайн Tabler).
2. REST API: Откройте инструменты разработчика в браузере (F12) -> вкладка Network. Добавьте машину в избранное или смените статус заявки: убедитесь, что уходят асинхронные запросы (GET/POST/PATCH) и возвращаются статусы 200/201 без полной перезагрузки страницы.
